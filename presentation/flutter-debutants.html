La vraie question

  
Qui dessine l'écran ? 🎨

  

    
Natif
📝 Ton code➜🧱 Composants du système➜📱 Écran

    
React Native
📝 Ton code JS➜🌉 Pont vers le système➜📱 Écran

    
Flutter
📝 Ton code Dart➜🎮 Moteur de Flutter➜📱 Chaque pixel

  






  
Alors, on choisit quoi ?

  
Natif ou multiplateforme ? 🤔

  

    
🎯 Le natif, pour…
  • des besoins très liés au système (montres, widgets avancés)
  • des performances extrêmes (jeux 3D)

    
🚀 Le multiplateforme, pour…
  • la grande majorité des apps
  • les petites équipes, les MVP, les startups

Stateless ou Stateful ?

  
Les widgets qui changent 🔄

  

    

      
🪨 StatelessWidget
Ne change jamais tout seul : un titre, une image

      
⚡ StatefulWidget
A un état qui change : un score, un choix

      
setState() = « l'état a changé, redessine l'écran ! »
